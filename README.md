# Student Helper AI

Ez a projekt egy egyszerű Python alkalmazás, amely segíti a hallgatókat különböző feladatokban.

## Futtatás


1. Telepítsd a függőségeket:
   ```bash
   pip install -r requirements.txt
   ```
2. Indítsd el az alkalmazást Streamlittel:
   ```bash
   streamlit run app.py
   ```

## Függőségek

A szükséges csomagokat a requirements.txt tartalmazza.

## Szerző

Add meg itt a neved vagy a csapatod nevét.
